# Mobile landscape layout

## 목표와 범위

스마트폰 가로 화면에서 네 경로의 본문과 입력창을 조작할 수 있도록 배치를 조정한다. 설정의 System note는 완전히 제거한다. Planner·저장 구조·하단 메뉴의 표시 정책은 그대로 유지한다.

## 적용 기준

- Tailwind의 `phoneLandscape` 변형: 가로 방향, 높이 600px 이하, 너비 1024px 이하.
- 본문은 `100dvh`와 문서 스크롤을 사용한다. 화면에 맞추려고 지령 내용이나 달력을 잘라내지 않는다.
- `viewportFit: cover`와 safe-area 여백으로 노치와 홈 제스처 영역을 확보한다.
- 하단 메뉴 여유 공간은 본문과 모달이 같은 CSS 값을 사용한다.

## 작업 순서

1. 공통 화면: 노치 여백, 동적 높이, 하단 메뉴 여백, 짧은 화면의 제목 간격.
2. 지령: 처리 버튼을 본문 옆에 배치하고 글자·문단 간격을 가로 화면에 맞춘다.
3. 달력: 날짜별 목록을 오른쪽에 배치하고 날짜 셀 높이는 고정하여 일정 수에 따라 늘어나지 않게 한다.
4. 루틴: 요일 선택과 목록 간격을 줄이고 시간 선택기를 모달 안에서 펼친다.
5. 설정: System note와 빈 사이드바 열을 제거하고 가로 화면에서 설정과 백업을 두 열로 배치한다.
6. 모달: 실제 화면 높이에서 메뉴와 safe-area 공간을 뺀 최대 높이를 사용하고 내부 스크롤을 허용한다.

## 확인 기준

- 가로 화면에서 완료·실패 버튼을 사용할 수 있다.
- 달력 일정 제목, 추가 일정 수, 수행·실패 수가 서로 겹치지 않는다.
- 할 일·루틴·실패 사유·수행 기록 창의 마지막 버튼까지 스크롤할 수 있다.
- 루틴의 시·분 목록을 스크롤하고 선택 결과를 확정할 수 있다.
- 설정에 System note 또는 제거된 패널의 빈 열이 남지 않는다.
- 세로·데스크톱의 화면 구성과 기존 상태 전이·메뉴 표시 정책을 유지한다.

## 실행 상태와 인계

사용자의 검증 생략 요청에 따라 테스트·타입 검사·빌드·브라우저 검증은 실행하지 않는다. 비교용 폴더와 소스 ZIP을 갱신한다. APK는 별도 빌드 요청 전까지 갱신하지 않는다.

## 복구

이 변경의 레이아웃·스타일·Viewport 설정만 이전 소스로 되돌린다. 등록된 Task·Routine과 수행 이력은 변경하거나 삭제하지 않는다.
