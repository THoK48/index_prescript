# 루틴 자동 밀기

## 목적

루틴 종료 시간이 늘어나 뒤 루틴과 겹칠 때 기존 간격을 유지한 채 이후 루틴을 일괄 이동한다. 이 계산은 Routine 편집기 안에서만 수행하며 Planner 우선순위와 ACTIVE 상태를 변경하지 않는다.

## 편집 범위

- `반복 전체`: 반복 템플릿의 시간과 필요한 경우 요일을 변경한다.
- `오늘 하루만`: 로컬 날짜별 시간 예외를 저장하고 반복 템플릿은 유지한다.
- 오늘 발생하지 않는 Routine에는 오늘만 변경을 적용하지 않는다.

## 계산

- 수정 전 종료와 수정 후 종료의 차이를 이동량으로 사용한다.
- 직접 충돌이 발생한 경우에만 자동 밀기 옵션과 결과 미리보기를 표시한다.
- 원래 수정 대상 뒤에 있던 Routine에 같은 이동량을 적용해 기존 간격을 유지한다.
- 반복 전체는 공유 요일을 기준으로 계산하고 오늘만 변경은 오늘과 익일의 실제 발생 구간을 확인한다.
- 잠금 Routine은 미리보기에 제외 대상으로 표시하며 이동하지 않는다.
- 이동 후 남은 겹침은 적용 차단 사유로 표시한다.
- 익일 이동 또는 자정 횡단은 별도 확인 없이는 저장하지 않는다.

## 저장과 알림

- 편집 대상과 연쇄 이동 결과는 하나의 로컬 저장 전이로 적용한다.
- 일부 Routine만 저장되는 부분 적용은 허용하지 않는다.
- 상태 저장 후 기존 네이티브 동기화가 예약 알림을 취소·재생성한다.
- 현재 ACTIVE Ticket과 완료·실패·무효 이력은 변경하지 않는다.

## 기존 데이터

- 기존 Routine은 `locked: false`, 날짜 예외 없음으로 정규화한다.
- 날짜 예외는 Routine당 최근 31건으로 제한한다.
- 사용자가 별도로 요청하기 전까지 자동 테스트, typecheck, build는 실행하지 않는다.
