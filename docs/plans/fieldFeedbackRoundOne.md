# 실사용 피드백 1차 보완

## 목적

실제 Android 사용에서 확인된 달력 위젯 호환성, 한국어 목적격 조사 표기, System fallback 고정 목록 문제를 보완한다. 하나의 ACTIVE 지령과 결정론적 Planner 원칙은 유지한다.

## 범위

1. 달력 위젯의 42개 날짜 셀을 동적 중첩 `RemoteViews`에서 표준 `GridView`/`RemoteViewsService` 컬렉션으로 교체한다.
2. 설정 화면에서 Android의 실제 달력 위젯 고정 요청을 호출할 수 있게 한다. 지원하지 않는 런처에서는 위젯 선택기를 안내한다.
3. 한글 음절의 종성 유무에 따라 `을/를`을 선택하고, 뒤쪽 문장부호와 숫자를 처리한다. 발음을 확정할 수 없는 영문·기타 문자는 `항목을` 표현으로 우회한다.
4. System fallback 편집기는 설정 화면에서 기본적으로 접어 두며 제목 행으로 펼친 뒤 문구·예상 시간·순서를 추가, 수정, 삭제, 이동, 기본값 복원할 수 있게 한다.
5. fallback 설정을 기존 `ticketPlannerV2` 상태와 JSON 백업에 포함한다. 기존 저장 데이터에는 기본 목록을 자동 보완한다.

## 불변조건

- Planner의 우선순위 계층과 ACTIVE 최대 1개 제한은 변경하지 않는다.
- fallback 선택은 저장된 배열 순서와 처리된 fallback 개수만 사용하며 무작위 선택을 도입하지 않는다.
- fallback ID를 source ID에 사용하여 문구나 순서를 바꿔도 이상 지령 직후 재발행 방지 이력을 유지한다.
- 원본 Task와 할 일 제목은 조사 처리를 위해 변경하지 않는다.
- 위젯에는 할 일 제목을 복사하지 않고 날짜별 미완료 개수만 전달한다.

## 저장 호환성

기존 `Settings`에 `systemFallbacks`가 없으면 정리, 물, 걷기, 휴식, 스트레칭의 기본 목록을 복사한다. 가져온 항목은 ID, 비어 있지 않은 문구, 1~30분 범위, 최대 12개를 검증하며 유효 항목이 하나도 없으면 기본 목록으로 복구한다.

## 검증 경계

테스트 케이스와 네이티브 소스는 함께 갱신하지만, 사용자가 별도로 요청하기 전까지 `npm test`, `npm run typecheck`, `npm run build`와 APK 빌드는 실행하지 않는다. 달력 위젯 교체는 다음 APK를 설치한 뒤 실제 런처에서 확인해야 한다.
