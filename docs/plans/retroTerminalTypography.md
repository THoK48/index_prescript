# CRT 단말기 타이포그래피 조정

## 1. 배경과 목표

화면 전체를 큰 원형 점으로 표시한 시안에서 벗어나, 사용자가 승인한 각진 글꼴·낮은 번짐·복호화 뒤 짧은 잔광을 적용한다. 파란색 CRT 디자인을 유지한다.

## 2. 제외 사항

APK·웹 빌드, 테스트·타입 검사·브라우저 검증, GitHub 키 등록, 커밋·푸시는 실행하지 않는다. 상태 머신과 발급음·실패음은 변경하지 않는다.

## 3. 범위

기본 글꼴·지령 본문 크기/행간·원형 도트의 사용 범위·복호화 완료 시각 효과만 변경한다.

## 4. 입력과 의존성

공식 `quiple/galmuri` v2.40.4 배포의 GalmuriMono11 WOFF2 및 LICENSE.txt를 변경 없이 로컬에 보관한다. 사용자가 준 Gothic Dot Round는 작은 표시용으로 유지한다. 외부 CDN을 런타임에 호출하지 않는다.

## 5. 구현

1. 한글 고정폭 픽셀 글꼴을 기본으로 연결하고 지령 본문은 원본 픽셀 단위에 맞춘 24px/36px로 표시한다.
2. 원형 도트는 수행 횟수와 발령 시각에만 적용한다.
3. DecryptingText가 완료 상태를 표시하면 650ms의 단발성 잔광을 재생한다. 계속 깜빡이는 효과는 넣지 않는다.
4. 잔광은 현재 글자색을 따르고, 실패 중에는 해당 애니메이션을 꺼 붉은 전환과 충돌하지 않게 한다.
5. 모션 감소 환경에서는 기존 즉시 표시를 유지하며 잔광도 비활성화한다.

## 6. 확인 범위

코드와 자산 연결만 확인한다. 기존 사용자 방침과 빌드 중지 요청에 따라 실행 검증을 생략한다.

## 7. 복구

기본 `--terminalFontFamily`를 `gothicDotRound`로 바꾸고 본문 크기/행간과 잔광 관련 변경을 되돌리면 직전 시안으로 돌아간다. 기존 폰트 자산은 삭제하지 않는다.

## 8. 위험과 대응

작은 글자와 고해상도 화면에서 느껴지는 픽셀 선명도는 사용자 화면 피드백으로 조정한다. 실패 색상 우선권과 모션 감소 분기를 CSS에서 명시한다.

## 9. 인계

실행 중인 개발 서버가 소스 변경을 반영한다. 기존 APK에는 이번 변경이 포함되지 않으며, 실제 화면 확인과 APK 재빌드는 사용자 요청 이후 진행한다.

후속 APK 요청에 따라 2026-10-15 v1.0.2를 빌드했다. 웹/Android 빌드 성공과 APK 내 픽셀 글꼴·도트 글꼴·라이선스·잔광 CSS 포함을 확인했다. 실기기 화면 검증은 실행하지 않았다. 자세한 산출물 정보는 `mobileBuild.md`를 따른다.
