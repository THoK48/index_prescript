# 할 일·루틴 삭제 되돌리기

## 목적

모바일에서 작은 삭제 버튼을 잘못 눌러 Task 또는 Routine을 잃는 문제를 확인창 없이 복구한다.

## 동작

- 삭제는 즉시 저장하되 화면 하단에 5초 동안 `되돌리기`를 표시한다.
- 복원 시 새 ID를 만들지 않고 삭제 전 원본 ID와 모든 필드를 그대로 사용한다.
- 새 항목이 같은 마감 시각 또는 같은 요일·루틴 시작 시각을 이미 차지하면 중복을 만들지 않고 이유를 표시한다.
- 연속 삭제 시 가장 최근 항목만 되돌릴 수 있다.
- 되돌리기 알림을 조작하는 동안 하단 내비게이션을 유지한다.

## 불변조건

- 기존 ACTIVE 지령과 완료·실패 이력은 삭제 또는 복원으로 변경하지 않는다.
- Task·Routine 복원은 Planner를 즉시 실행하거나 현재 ACTIVE를 교체하지 않는다.
- 사용자가 별도로 요청하기 전까지 자동 테스트, typecheck, build는 실행하지 않는다.
